# スプレッドシート同期（F-20）セットアップ

宿泊記録を端末のlocalStorageだけでなく、Googleスプレッドシートにも残すための設定手順。
**この設定が済むまで、記録はブラウザのデータを消すと失われます。**

所要 10分。Shunのワークスペース（muge.cx）で作業してください。

---

## 1. スプレッドシートを作る

1. [sheets.new](https://sheets.new) で新しいスプレッドシートを作成
2. 名前を「Bonvoyラリー 台帳」などに変更
3. URLから **スプレッドシートID** を控える

   `https://docs.google.com/spreadsheets/d/`**`ここがID`**`/edit`

タブ（stays / hotels / scores / wants / meta）は初回同期時に自動で作られるので、手で作る必要はありません。

## 2. Apps Scriptを設置する

1. そのスプレッドシートで **拡張機能 → Apps Script** を開く
2. 既定の `Code.gs` の中身を全部消して、このリポジトリの [`apps-script/Code.gs`](../apps-script/Code.gs) を丸ごと貼り付け
3. 先頭の2行を埋める

   ```js
   var SHEET_ID = '手順1で控えたID';
   var TOKEN    = '好きな合言葉';   // 例: bonvoy-shun-2026-xxxxx
   ```

   合言葉は他人に同期先を触られないための鍵です。推測されにくい文字列にしてください。
   **このファイルをGitHubにコミットしないこと**（リポジトリの `Code.gs` は空のまま置いておく）。

4. 保存（フロッピーアイコン）

## 3. ウェブアプリとして公開する

1. 右上の **デプロイ → 新しいデプロイ**
2. 歯車 → **ウェブアプリ** を選択
3. 設定
   - 説明: `bonvoy sync`
   - **次のユーザーとして実行**: `自分`
   - **アクセスできるユーザー**: `全員`
4. **デプロイ** → 初回は認証画面が出るので許可する
   - 「このアプリは確認されていません」と出たら **詳細 → （安全ではないページ）に移動** で進む（自分が書いたスクリプトなので問題ありません）
5. 表示された **ウェブアプリのURL** を控える（`https://script.google.com/macros/s/..../exec`）

> アクセスを「全員」にする必要があるのは、アプリがブラウザから直接POSTするためです。
> URLを知っていても**合言葉がないと何も読み書きできません**。

## 4. アプリ側に設定する

1. https://kirin1009.github.io/Bonvoy/ を開く
2. **ラリー** タブ → 「スプレッドシート同期」
3. **同期URL** に手順3のURL、**合言葉** に手順2のTOKENを入れる
4. **設定を保存** → **いま同期する**
5. 「同期しました。」と出て、スプレッドシートに行が並べば完了

## 5. 動作確認（大事）

スプレッドシートを開いて、`stays` タブに宿泊が並んでいることを確認してください。
`meta` タブに最終同期時刻・宿泊件数・通算泊数が出ます。ここの泊数がアプリのHUDと一致していればOKです。

---

## 同期のふるまい

- **記録を触ると5秒後に自動同期**されます。アプリ起動時にも一度同期します
- **手動で同期したいときは「いま同期する」**
- マージは**足し算だけ**です。端末とシートのどちらか片方にしかない宿泊は、必ず両方に揃います。**同期で記録が減ることはありません**
- 同じ宿の同じチェックイン日は1件として扱われ、その場合は**端末側の内容**が採用されます（手元で泊数や価格を直した直後の同期を尊重するため）
- 通信できないときは静かに失敗します（手動同期のときだけエラーを表示）。記録は端末に残るので、次に繋がったときに同期されます

## 新しい端末に記録を戻す

紗也乃のスマホや機種変更後の端末では、手順4だけやれば全記録が降りてきます。

## 削除したいとき

同期は足し算なので、**アプリ側で消してもシートからは消えません**。
消したい宿泊は**スプレッドシートの `stays` タブで行ごと削除**してから、アプリ側でも削除してください。
（順番が逆だと、次の同期でシートから戻ってきます）

## 合言葉を変えたいとき

`Code.gs` の `TOKEN` を書き換えて **デプロイ → デプロイを管理 → 編集 → 新バージョン → デプロイ**。
URLは変わりません。アプリ側の合言葉も同じものに更新してください。

## うまくいかないとき

| 症状 | 原因と対処 |
|---|---|
| 「同期できませんでした: bad token」 | 合言葉が違う。`Code.gs` の TOKEN とアプリ側を一致させる |
| 「同期できませんでした: Failed to fetch」 | ウェブアプリのアクセス範囲が「全員」になっていない。デプロイ設定を確認 |
| シートは空だがエラーも出ない | `SHEET_ID` が違う。Apps Scriptのエディタで `testReadWrite` を実行してログを見る |
| 「Apps ScriptのウェブアプリURLを入れてください」 | URLが `https://script.google.com/` で始まっていない。`/exec` で終わるURLを貼る |

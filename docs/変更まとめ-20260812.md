# 変更まとめ（2026.08.11〜08.12）

デザインキックオフ〜世界対応ピボットまでの決定事項と成果物。詳細は `docs/要件定義.md`（常に最新）とIssue #4。

## 1. コンセプト・スコープの転換（最重要）

| 項目 | 旧 | 新 |
|---|---|---|
| 型 | スタンプラリー型（先に全店収録して埋める） | **台帳・育成型（泊まった宿がその場で記録され、世界に刻まれる）** |
| 記録対象 | 4カ国・対象ブランド116軒のみ | **世界中のBonvoy参画ホテル**（除外ブランドも記録可） |
| 既存116軒 | 母数そのもの | **シードカタログ**（GPS自動判子・伏せ判子・コンプ型の母数用に存続） |
| 楽しみの本体 | 集める | **リッチな3D世界が自分の宿泊で育つ**（泊まると宿のミニチュアが建つ） |

背景: Shunの実履歴が**年17カ国54泊・チタンエリート**で、4カ国収録では現実が入りきらなかった。

## 2. デザイン確定（Issue #4）

- **ビジュアルターゲット: A案「Grand Resort Atlas」**（夕景ミニチュア世界・磁器質の判子道・愛車の駒）。B/C案は不採用
- 決定プロセスを「完成イメージの絵を先に決めて実装が逆算する」方式に変更（CSSモック先行はチープ化するため廃止）
- 素材: S1未建設ベース世界／S2宿ミニチュア5軒／S3車2台（紫M3ツーリング・緑220クーペ）／S4アンカー座標JSON——**納品・検証・workマージ済み**（計445KB）
- **動くモックv7**: 「宿泊を記録」→判子刻印→車前進→初宿泊の宿が建つ、まで実素材で動作（`design/mock-world-v7.html`、Artifact公開中）
- 建物の接地ズレはココ側の補正値で解決済み
- **建物ルール**: ブランド区分×立地で建物タイプが変わる。luxury=ランドマーク級。再訪で育つ案は検討中
- 途中経過のv5/v6（台帳ファースト平面構造）は不採用。ただし「3秒で泊数・残数・現在地」「CTAは盤面外」の情報設計はUIレイヤーに引き継ぐ

## 3. ラリーの再定義（ラインナップ確定）

コンプは裏目標へ。主役は世界対象の**カウント型**:

- すぐ嬉しい: 紋章集め（ブランド5→10→15→20種）／ロングステイ（5連泊）／三大陸
- リーチ: 世界旅籠（5→10→20カ国）／定宿（同一宿3滞在）／JWの世界（5カ国）／**タイ通（タイで3→5→10軒）**
- じっくり: 世界のLC10軒／リッツの紋（3→5軒）／オートグラフ蒐集（5→10軒）／エリートロード（泊数10/25/50/75/100=双六の関門）
- 裏目標: **シリーズコンプ**（全リッツ・全JW・全LC…公式軒数を母数にするロマン枠）／シード国コンプ（日本・タイ全店制覇）

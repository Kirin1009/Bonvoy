## 納品ルール

1. 素材は `../assets/` に、モック・スタイル提案・パッチ案はこの `design/` に置く
2. 各納品に短い仕様メモ（.md）を添える: 何を作ったか / 想定の使われ方 / サイズ・形式
3. ファイル名は英小文字ケバブケース（例: `tile-marble.webp`, `gate-silver.webp`, `pawn-shun.webp`）
4. ブランチ＋PRで提出。mainへ直pushしない

## 世界観の要点（詳細はAGENTS.md）

- クリーム大理石 × ネイビー × 真鍮ゴールド ＋ 判子朱（#D9483B系）
- 俯瞰55度・夕暮れの光・大人向けの上品なデフォルメ・画像内に文字を入れない
- 判子文化（かすれ・傾き・伏せ判子）はこのアプリのアイデンティティなので壊さない
